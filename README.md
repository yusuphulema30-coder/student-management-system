# 🎓 Student Management System

## 📋 Description
A Python OOP-based student management system that registers 
students, enrolls them into courses, tracks grades and 
attendance, and saves all data permanently using JSON 
file handling.

## 🚀 Features
- Register students with ID, name and programme
- Enroll students into courses
- Track grades and calculate letter grades automatically
- Mark and track student attendance
- Generate ranked performance reports
- Identify top performers and at-risk students
- Save and load all data using JSON file handling
- Support for Postgraduate and International student types

## 🛠️ Technologies Used
- Python 3.12+
- Object-Oriented Programming (OOP)
- JSON (JavaScript Object Notation) for data persistence

## 📦 How To Run
Clone the repository:
git clone https://github.com/yusuphulema30-coder/student-management-system

Navigate into the folder:
cd student-management-system

Run the program:
python student_management_system.py
